# College Project Marketplace — Frontend Application

A modern, responsive, security-first frontend built for verified college and university students to discover academic projects, view watermarked PPT previews (`♥ ♥ ♥ ♥ ♥`), shortlist up to 3 projects, book 5-minute Google Meet guidance sessions, and purchase complete project deliverables.
